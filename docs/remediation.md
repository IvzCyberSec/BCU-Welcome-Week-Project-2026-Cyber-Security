# Remediation

The main recommendations from the assessment are:

## 1. Disable Telnet

Remove Telnet access if it is not required.

## 2. Change Default Credentials

Change the camera's default username and password before deployment.

Use a strong and unique password.

## 3. Restrict Management Access

Only allow authorised devices or administrators to access the camera management interface.

## 4. Network Segmentation

Place cameras and other IoT devices on a separate network or VLAN where appropriate.

## 5. Reduce Exposed Services

Disable services that are not required for normal operation.

## 6. Update Firmware

Check whether the manufacturer provides security updates.

If the device is no longer supported, consider replacing it.

## 7. Monitor the Device

Monitor network traffic and administrative access for unusual activity.

## Summary

The main objective is to reduce the camera's attack surface and prevent unauthorised access to its management functions.
